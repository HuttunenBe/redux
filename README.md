# Redux Shopping Cart and Product Explorer

This project was built as part of my classwork to practise managing application data with Redux Toolkit and React Redux. It includes a product page, a shopping cart and a user page. Product and user data are stored in Redux and displayed through React components.

## Features
* Fetch and display products from the application state.
* Add products to the shopping cart.
* Prevent the same product from being added more than once.
* Remove individual products from the cart.
* Clear all products from the cart.
* Display the number of items in the cart.
* Fetch user data from an external API.
* Display a list of users and their names.
* Navigate between the Products, Cart and Users pages.

## Tech Stack
* React
* TypeScript and JavaScript
* Redux Toolkit
* React Redux
* React Router
* Axios
